# Phantom Road Studio

**Локальный AI-ассистент** на базе Qwen, Claude и Alice. Работает **без интернета** через [Ollama](https://ollama.com).

![Phantom Road Studio](phantom.png)

---

## ✨ Возможности

- 🧠 **Три ассистента:** Qwen, Claude, Alice — у каждого своя память и свои чаты
- 📄 **Читает документы:** `.txt`, `.md`, `.json`, `.docx`, `.pdf`, `.xlsx`, `.csv`
- 🖼 **Распознаёт картинки** — описывает, что видит (через llava)
- ✂ **Удаляет фон** у картинок (локально, rembg)
- 🧩 **Склеивает картинки** в ряд
- 🎵 **Играет музыку** со встроенным плеером
- 💾 **Память на диске** — переживает обновления и перезапуски
- 🔄 **Автообновление интерфейса** с GitHub — тихое, в фоне
- 🚫 **Работает без интернета** — после первичной установки

## 📋 Требования

- **Windows** 10 или 11 (64-bit)
- **[Ollama](https://ollama.com/download)** — установлена локально
- Модели в Ollama:
  - `qwen2.5` — основной ассистент
  - `llava` — распознавание картинок
  - `mistral` — ассистент Claude

---

## 🚀 Установка

### Шаг 1. Установи Ollama

Скачай с [ollama.com/download](https://ollama.com/download) → установи.

### Шаг 2. Скачай модели

Открой **PowerShell** (`Win + R` → `powershell` → Enter). Введи по очереди:

    ollama pull qwen2.5
    ollama pull llava
    ollama pull mistral

Каждая — Enter. Подожди 5–10 минут.

### Шаг 3. Запусти Ollama как службу

Открой **Параметры Ollama** в трее → включи **«Start Ollama on login»**.

*(Или создай ярлык `ollama app.exe` в папке автозагрузки: `Win+R` → `shell:startup`.)*

### Шаг 4. Скачай Phantom

Последний релиз — во вкладке **Releases** *(справа вверху)*.

### Шаг 5. Запусти `Phantom.exe`

Двойной клик. Готово.

## ⚙️ Настройка Ollama (важно!)

### Если у тебя мощная видеокарта

**Ничего делать не нужно.** Phantom работает на GPU — быстро.

Мощные: NVIDIA RTX 2060+, AMD RX 6000+.

### Если у тебя слабая или встроенная видеокарта

**Сделай `OLLAMA_VULKAN=0`** — иначе модели не загрузятся, Phantom ответит пусто.

Слабые: NVIDIA GTX 1050/1650, AMD RX 560/570, Intel HD, Vega, ноутбуки.

**Как:**

1. Нажми **`Win + R`** → введи **`sysdm.cpl`** → **Enter**.
2. Вкладка **«Дополнительно»** → **«Переменные среды»**.
3. **Верхний блок** → **«Создать»**.
4. **Имя:** `OLLAMA_VULKAN`
5. **Значение:** `0`
6. **OK → OK**.
7. **Перезагрузи компьютер.**

## 🎮 Использование

- **Левый сайдбар** — переключение между Qwen, Claude, Alice. У каждого свои чаты.
- **Кнопка скрепки** — прикрепить картинку, музыку или документ.
- **Вкладка «Работа с картинками»** — склейка, удаление фона, поворот, скачивание.

## 🔒 Безопасность

Phantom **полностью локальный**:

- Все запросы идут на `localhost:11434` (Ollama на твоей машине).
- Никакие данные не уходят в интернет.
- Интернет нужен **только для автообновления** интерфейса.

---

## 🛠 Если Windows Defender ругается

Иногда Defender блокирует **неподписанные exe-файлы**. Это **ложное срабатывание**.

**Как запустить:**

1. При появлении окна Defender → **«Подробнее»**.
2. → **«Всё равно выполнить»**.

Мы работаем над получением подписи.
